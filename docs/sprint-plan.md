# Sprint plan

## Team capacity

A sprint was two weeks: ten working days, less one personal day, with one further day set aside for Scrum meetings.

| Role | Days available | Days for Scrum activities | Hours per day | Effort-hours |
|---|---|---|---|---|
| Developer | 9 | 1 | 3–5 | 24–45 |
| Developer | 8 | 1 | 2–3 | 14–21 |
| Developer | 8 | 1 | 2–4 | 14–28 |
| Product owner | 8 | 1 | 1–2 | 7–14 |
| Scrum master | 8 | 1 | 1–2 | 7–14 |
| **Team** | | | | **66–122** |

## Release plan

| Sprint | User stories |
|---|---|

| Sprint 2 | 12, 2, 3, 6 |
| Sprint 3 | 4, 5, 8 |

## Sprint 1 goal

> Build the foundational system features that enable seamless connectivity, accessibility, and compliance visibility for pilots and airline operations.

## Sprint 1: estimate against actual

Each story was broken into tasks with an estimate in hours. The actual hours were recorded during the sprint.

| Story | Task | Estimated (h) | Actual (h) |
|---|---|---|---|
| 9 Multiple languages | 9.1 Find a tool to translate the language | 4 | 6 |
| | 9.2 Implement it on each page | 11 | 16 |
| | 9.3 Test | 5 | 9 |
| | **Story total** | **20** | **31** |
| 1 Airline sync and duty alerts | 1.1 Connect to the API | 1 | 7 |
| | 1.2 Build the alert system | 1 | 4 |
| | **Story total** | **2** | **11** |
| 11 Sync across devices | 11.1 Write the code | 2 | 6 |
| | 11.2 Test and fix the code | 1 | 5 |
| | **Story total** | **3** | **11** |
| 10 Dashboard | 10.1 Get the sleep data and build the dashboard | 1 | 2 |
| | 10.2 Calculate risk, schedule, and score | 1 | 2 |
| | **Story total** | **2** | **6** |
| 7 Compliance report | Generate the safety report | 1 | 2 |
| 12.1 Fatigue prediction, first part | Collect the data | 4 | 6 |
| **Sprint 1 total** | | **32** | **67** |

The dashboard story's recorded total (6 hours) is two hours more than its two tasks add up to; the sprint total uses the recorded story totals.

### What this showed

- The sprint took about twice the estimate, and every story ran over.
- The smallest estimates were the least accurate: a 2-hour story took 11 hours.
- The work still fitted inside the team's capacity of 66 to 122 hours, because the plan had been made from the hours people really had.
